# 🎓 Quiz por Matérias PRO ULTRA

> Um jogo de perguntas e respostas (Quiz) interativo, moderno, responsivo e 100% offline desenvolvido em **HTML5**, **CSS3** e **JavaScript puro (Vanilla JS)**.

---

## 🌟 Funcionalidades Principais

* **Modo Capa / Home Interativa:** Tela de boas-vindas com acesso rápido a partidas gerais ou configurações avançadas.
* **Múltiplas Matérias:** Teste seus conhecimentos em:
  * 🌐 Geral
  * 🌎 Geografia
  * 📝 Português
  * 🔢 Matemática
  * 📜 História
  * 🔬 Ciências
  * 🇬🇧 Inglês
  * 💻 Informática
  * ⚽ Educação Física
* **Sistema de Progressão (XP & Níveis):** Ganhe experiência (XP) a cada resposta correta e suba de nível.
* **Modos de Jogo & Dificuldade:** 
  * Escolha entre níveis **Fácil**, **Médio** e **Difícil**.
  * Modos especiais: **Normal**, **Relâmpago ⚡** e **Desafio 🧠**.
* **Ferramentas de Ajuda (Power-ups):**
  * **💡 50/50:** Elimina duas alternativas incorretas.
  * **⏭️ Pular:** Avança para a próxima questão sem penalidade de pontos.
* **Ranking & Estatísticas Locais:** Acompanhe seu desempenho com histórico de partidas, porcentagens de acerto, recordes por matéria e ranking salvos diretamente no navegador (`localStorage`).
* **Suporte a Dark Mode:** Alterne facilmente entre os temas Claro e Escuro com animações suaves.
* **Design Responsivo:** Totalmente adaptado para smartphones, tablets e computadores.

---

## 🚀 Como Executar o Projeto

Como o quiz utiliza apenas tecnologias nativas da Web e não requer servidores de backend ou bancos de dados externos, executá-lo é extremamente simples:

1. Baixe ou copie o código fonte do arquivo HTML do projeto (ex: `quiz.html`).
2. Salve o arquivo em seu computador.
3. Dê um **duplo clique** no arquivo salvo para abri-lo em qualquer navegador web moderno (Google Chrome, Microsoft Edge, Firefox, Safari, etc.).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das telas e elementos.
* **CSS3:** Estilização moderna com variáveis CSS (`:root`), flexbox, grid, gradientes e animações suaves.
* **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM, temporizadores e persistência de dados.
* **LocalStorage API:** Armazenamento local de pontuações, recordes, XP e histórico do jogador.
* **Web Audio API:** Geração de efeitos sonoros sintéticos (acertos, erros e finalização) sem dependência de arquivos de áudio externos.

---

## 📦 Estrutura do Código

O código está contido em um arquivo único estruturado em seções claras:
* **Styles (`<style>`):** Variáveis de cores, temas (Dark/Light), layout responsivo e transições.
* **Interface HTML (`<body>`):** Telas separadas por blocos (`Capa`, `Menu`, `Quiz` e `Resultados`).
* **Lógica JavaScript (`<script>`):** Banco de questões estruturado, controle de estados, temporizador, cálculo de pontuação, experiência e manipulação do armazenamento local.
